# FAQ

## 手首にパネルが出ない {#no-panel}

- SteamVR と OverRec が起動しているか確かめます。PC の設定画面の右下の **SteamVR** が「連携中」なら連携しています。
- 「未起動」のままのときは、SteamVR を起動してから数秒待ちます。変わらないときは、OverRec を起動し直します。
- 手首を、腕時計を見るように顔へ向けます。パネルの面が顔を向いたときに出ます。
- 動かしたあとで見失ったときは、PC の設定画面の「VR操作」→ **「手首に戻す」** を押します。
- パネルを小さくしていると、[小さな表示](/customize#mini) だけが出ます。指して押すと元に戻ります。
- SteamVR を通さない遊び方（VDXR や Meta の OpenXR ランタイム）では利用できません。

## OBS につながらない {#no-obs}

PC の設定画面の右下の **OBS** が「未接続」のときは、「困ったとき」のログに理由が出ています。

- OBS Studio が起動しているか確かめます。
- OBS の「ツール」→「WebSocket サーバー設定」で、「WebSocketサーバーを有効にする」にチェックが入っているか確かめます。
- ポートとパスワードが、OBS の画面と同じか確かめます。「接続」→ **「接続をテスト」** で確かめられます。
- OBS Studio が 28 より古いと使えません。

OBS をあとから起動したときは、数秒で自動的につながります。

## 「リプレイ保存」ができない {#no-replay}

- ボタンが「リプレイ開始」のときは、リプレイバッファが止まっています。押すと始まります。
- 「OBS のリプレイバッファが無効です」と出るときは、PC の設定画面の「OBS」→ **「OBS に設定」** で有効にします。
- 有効にしても動かないときは、OBS を起動し直します。
- 保存したファイルは、「OBS」→「保存先」の「フォルダーを開く」で確かめられます。

## 「チャプター」が押せない {#no-chapter}

チャプターは、OBS 30.2 以降で、録画中だけ押せます。押せてもエラーになるときは、OBS の録画フォーマットを Hybrid MP4 にします。

## マイクのボタンが「マイクなし」になる {#no-mic}

OBS に音声入力がないか、選んだ入力が見つかりません。PC の設定画面の「OBS」→「マイクに使う入力」で選び直します。

## パネルを押すと、ゲームも反応する {#game-input}

SteamVR の設定で **「Enable global input from overlays」** を有効にします。
有効にしても、パネルをつかんでいる間のスティックは、ゲームにも届きます。

## ボタンを割り当てたのに動かない {#bindings}

- SteamVR の割り当て画面で、OverRec の割り当てになっているか確かめます。
- OBS とつながっているか確かめます。

## アイコンの形が違う、文字が出ない {#icons}

Windows 10 では、一部のアイコンの形が変わります。文字がまったく出ないときは、[不具合の報告](#report) からお知らせください。

## SteamVR を終了すると、OverRec も終了する {#auto-quit}

初期設定の動きです。残したいときは、「一般」→「SteamVR と同時に終了」をオフにします。

## 設定を最初からやり直したい {#reset}

「困ったとき」→「設定フォルダー」の「フォルダーを開く」でフォルダーを開き、OverRec を終了してから、そのフォルダーを削除します。次に起動すると、初回ガイドから始まります。
OBS のパスワードは Windows の資格情報に残ります。変えるときは、「接続」で入力し直します。

## SteamVR に OverRec の項目が残った {#leftover}

SteamVR を止めたままアンインストールすると、SteamVR の起動時のアプリの一覧に OverRec が残ることがあります。
SteamVR の設定の「スタートアップ / シャットダウン」から、オフにできます。

## 不具合の報告・要望 {#report}

[GitHub の Issues](https://github.com/misyaguziya/OverRec-Docs/issues) で受け付けています。「不具合の報告」か「要望」を選んでください。

不具合の報告には、次の内容を添えてください。

- OverRec のバージョン（PC の設定画面の左下）
- 使っている VR 機器と、つなぎ方（Steam Link、Virtual Desktop など）
- OBS Studio のバージョン
- 行った操作と、起きたこと
- ログ（「困ったとき」→「ログ」の「コピー」）。あれば、設定フォルダーの `error.log` も

:::caution
Issues は公開の場所です。ログには、ファイルの保存先（ユーザー名を含むパス）が出ることがあります。貼る前に、ユーザー名の部分を消してください。
:::

GitHub のアカウントがない場合は、BOOTH のメッセージでも受け付けています。
