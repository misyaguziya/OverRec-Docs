# インストール

## 入れる

1. [BOOTH](https://misyaguziya.booth.pm/items/9175989) からダウンロードした zip を開き、中のインストーラー（`OverRec_…_x64-setup.exe`）を実行します。
2. 「Windows によって PC が保護されました」と表示された場合は、**「詳細情報」** を押してから **「実行」** を押します。
3. 言語を選び、案内に沿ってインストールします。管理者の権限は要りません（自分のユーザーにだけ入ります）。

zip には、かんたんな使い方（`README.txt`）と利用規約（`LICENSE.txt`）も入っています。

:::note
Windows 11 の「スマート アプリ コントロール」がオンの PC では、起動できない場合があります。
:::

## 新しい版にする

新しい版のインストーラーを、そのまま実行します。設定は引き継がれます。

新しい版が出ると、PC の設定画面の下に知らせが出ます。「更新内容」で変わった点を、「BOOTH を開く」でダウンロードのページを開けます。
知らせが要らないときは、「一般」→「起動時に新しいバージョンを確認」をオフにします。

## アンインストール {#uninstall}

Windows の「設定」→「アプリ」→「インストールされているアプリ」から **OverRec** をアンインストールします。

**先に SteamVR を起動しておいてください。** 「SteamVR と同時に起動」の登録は、SteamVR が動いている間にしか外せません。

設定とログを残さず消したいときは、アンインストールの前に、設定画面の「困ったとき」→「設定フォルダー」の「フォルダーを開く」で場所を確かめておき、アンインストールのあとでそのフォルダーを削除します。
OBS のパスワードは、アンインストールのときに Windows の資格情報から消えます。
