# Installing

## Install

1. Open the zip downloaded from [BOOTH](https://misyaguziya.booth.pm/items/9175989) and run the installer in it (`OverRec_…_x64-setup.exe`).
2. If "Windows protected your PC" appears, press **"More info"**, then **"Run anyway"**.
3. Choose a language and follow the installer. No administrator rights are needed (it is installed for your user only).

The zip also has a short guide (`README.txt`, in Japanese) and the license agreement (`LICENSE.txt`).

:::note
On a PC with Windows 11's Smart App Control turned on, OverRec may not start.
:::

## Updating

Run the new version's installer as it is. Your settings are kept.

When a newer version is out, a notice appears at the bottom of the PC settings window. "What's new" opens what changed, and "Open BOOTH" opens the download page.
If you don't want the notice, turn off "General" → "Check for updates at startup".

## Uninstalling {#uninstall}

Uninstall **OverRec** from Windows "Settings" → "Apps" → "Installed apps".

**Start SteamVR first.** "Start with SteamVR" can only be unregistered while SteamVR is running.

To leave no settings or logs behind, find the folder before uninstalling with "Troubleshooting" → "Settings folder" → "Open folder" in the settings window, and delete that folder after uninstalling.
The OBS password is removed from Windows Credential Manager when OverRec is uninstalled.
